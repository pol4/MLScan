# Скриншоты UI MLScan

Здесь размещаются скриншоты веб-интерфейса, на которые ссылается
[`../11-ui-and-operations.md`](../11-ui-and-operations.md) §2.6. Пока файлов нет — раздел содержит
**инструкцию по съёмке** и **список ожидаемых изображений**. Эскизы (wireframes) уже встроены в
`11-ui-and-operations.md`; их следует **заменить реальными скриншотами** с указанными именами.

## Требования к съёмке
- Доступ: `https://mlscan.platform.rtx.local` (Keycloak, realm `tenants`). Для админ-разделов —
  группа `mlscan-admin` (роль `admin`).
- Браузер: светлая тема, ширина окна ~1600 px. Снимать **область контента** раздела (без лишних
  вкладок браузера). Формат — PNG.
- При съёмке — не показывать секреты/токены/персональные данные (маскировать).
- Имена файлов — строго как в таблице ниже (на них ссылается документация).

## Куда встраивать
В `11-ui-and-operations.md` §2.6 у каждого раздела есть эскиз и ссылка вида
`![Сканы](screenshots/ui-scans.png)` — достаточно положить файл с этим именем, и изображение
подхватится автоматически. При съёмке новых экранов — добавляйте строку в таблицу выше и ссылку в §2.6.
