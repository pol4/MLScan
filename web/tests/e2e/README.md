# e2e (Playwright) для нового UI (`/app`)

Тесты гоняются против **BFF analytics** напрямую, эмулируя заголовки oauth2-proxy
(`X-Forwarded-User`/`X-Forwarded-Groups`); браузерная аутентификация Keycloak не нужна.

## Запуск

```bash
kubectl -n t-mlscan-app port-forward svc/mlscan-analytics 18080:8080
cd web && npm run e2e                 # весь набор
npx playwright test tests/e2e/runs.spec.ts   # отдельный файл
```

Стабильный эндпоинт можно задать через `E2E_BASE_URL` (например, in-cluster адрес при запуске из CI/пода).

## Важно про `kubectl port-forward`

Локальный `kubectl port-forward` **нестабилен при параллельных/долгих соединениях** (может «зависать»
на нескольких одновременных запросах). Поэтому:

- конфиг использует `workers: 1` и 1 ретрай;
- надёжнее запускать **пофайлово** (свежий forward на файл) либо против стабильного эндпоинта
  (`E2E_BASE_URL`, напр. в кластере).

## Состав

| Файл | Что проверяет |
|------|----------------|
| `smoke.spec.ts` | навигация, Обзор, Проверки, Каталог, a11y (axe: critical/serious) |
| `runs.spec.ts` | фильтры+сброс, сохранение вида, «только риск/сбои», выбор для сравнения |
| `run-detail.spec.ts` | вкладки прогона, «Доказательства» (digest), фильтр кейсов |
| `compare.spec.ts` | заголовок сравнения, тренды, подсказка без выбора |
| `catalog.spec.ts` | разделы каталога; регресс «Наборы вопросов» (активный набор виден) |
| `admin.spec.ts` | форма судьи (движок/модель/URL/порог/шаблон) + сохранение; паритет операций |
| `i18n.spec.ts` | EN-локаль (`localStorage.mlscan_lang=en`): навигация/Обзор/Админ |
